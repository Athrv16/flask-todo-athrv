About This To-Do App

Simple, Efficient, and Built for Learning

📌 Project Purpose

This To-Do web application was built as a learning project to explore and practice the Flask web framework. It helps manage tasks efficiently with core CRUD operations (Create, Read, Update, Delete).

🛠️ Features

  • ✅ Create and manage To-Do items
  • ✅ Update or delete tasks easily
  • ✅ Fully responsive UI with Bootstrap

💻 Technologies Used

  • ✔️ Flask (Python)
  • ✔️ SQLite (Database)
  • ✔️ HTML & CSS
  • ✔️ Bootstrap 5
